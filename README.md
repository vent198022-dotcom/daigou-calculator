# 商品費用試算表

線上使用：https://vent198022-dotcom.github.io/daigou-calculator/

手機開上面的網址，用瀏覽器「加到主畫面」就能像 App 一樣使用。

## 計算方式

總計 = (商品價格 × 折扣 × 現金賣出匯率 + 重量 × 運費) × (1 + 手續費%)

| 欄位 | 輸入方式 |
| --- | --- |
| 商品價格 | 輸入任一幣別的價格，其他幣別會依匯率自動換算 |
| 折扣 | 輸入折數：9 = 9 折、85 或 8.5 = 85 折，留空視為不打折 |
| 現金賣出匯率 | 自動抓台灣銀行現金賣出匯率 × 1.025（加幣再 × 1.05），可手動修改 |
| 重量 (磅) | 運費日圓每磅 120，其他幣別每磅 180 |
| 手續費 (%) | 輸入 10 = 10%，可快速選 10 / 12 / 15 |

折扣、重量、手續費在所有幣別間同步。

## 利潤（美金）（表格最下面一行）

- 利潤 = 美金總計 − 成本
- 成本 = 商品價格 × 折扣 × 台銀原始現金賣出匯率 + 重量 × 180（不加 2.5% 匯率加價、不加手續費）
- 價格、折扣、重量用美金那列的數字；台銀匯率自動抓取
